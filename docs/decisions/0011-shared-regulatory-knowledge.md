# ADR 0011: Share reviewed regulatory knowledge across organizations

**Status:** Accepted

Submitted analysis reviews and material conformity corrections create draft knowledge examples so a correction made by one user can improve later AI results for every user after platform review. This is a deliberate exception to ADR 0008’s tenant-scoped reads: ownership and provenance remain attached to the originating organization, while only administrator-approved, sanitized scenarios, outcomes, and guidance are reused globally. Raw project profiles, evidence, organization identifiers, contacts, and file URLs remain tenant-isolated and never enter shared retrieval content. Customer feedback by itself is not regulatory knowledge and cannot influence AI until an authorized platform operator approves the resulting example.
